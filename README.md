### 📂 Featured Projects

#### 🤖 Hire But Smarter
- **Tagline:** Talent Intelligence system for the post-resume era
- **Description:** Recruiters can't verify developer skills from resumes alone — no proof of real project complexity or actual coding ability.
- **Highlights:** Extracts verified skills and computes explainable Potential Score from public GitHub. AI Hiring Agent answers recruiter questions grounded in real repo data with citations. Side-by-side candidate comparison with JD match scoring and PDF portfolio export.
- **Impact:** Built for IIT Kanpur Techkriti '26 × Eightfold AI Hackathon — **Won 2nd Prize**
- **Tech:** Next.js, Supabase, Gemini AI, D3.js, Tailwind CSS
- **Source Code:** [Hire But Smarter](https://github.com/TheVivekRajput002/HireButSmarter) | **Live:** [hire-but-smarter.vercel.app](https://hire-but-smarter.vercel.app)

#### 🔁 AI-N2N: Visual Workflow Builder & Execution Engine
- **Tagline:** Interactive, AI-Powered Node-to-Node Workflow Builder & Execution Engine
- **Description:** A visual, user-friendly platform to design, version, execute, and monitor complex multi-agent AI workflows without writing repetitive backend integration code.
- **Highlights:** Visual DAG workflow editor with custom nodes, edges, and handles using React Flow. Topological sort (Kahn's Algorithm) execution engine handling skipped branches and node-level inputs. Integrated Google Gemini, OpenAI, and Groq APIs with dynamic variable extraction and output formatting.
- **Impact:** Empowers developers to construct and run multi-agent workflows with full step-by-step auditing and latency tracing
- **Tech:** Next.js, Express, PostgreSQL, Prisma, React Flow, Clerk, TypeScript
- **Source Code:** [AI-N2N](https://github.com/TheVivekRajput002/AI-N2N) | **Live:** [ai-n2n.vercel.app](https://ai-n2n.vercel.app)

#### 🎓 BrainFood
- **Tagline:** Learn, Grow & Get Inspired Through Short-Form Content
- **Description:** An engaging way to deliver bite-sized educational content, combining the addictive nature of short-form video with structured micro-learning and gamified progress tracking.
- **Highlights:** Dual-role auth system (User + Creator) with JWT HTTP-only cookies and Google OAuth 2.0. Event-driven achievement engine that auto-awards tiered badges and tracks scores on every user action. ImageKit CDN for optimized video and media delivery with TikTok-style vertical reel feed.
- **Impact:** Full-stack learning platform with gamified achievements, scrollable card decks, and creator tools — deployed live on Vercel + Render
- **Tech:** React 19, Node.js, Express 5, MongoDB, Tailwind CSS 4, ImageKit, JWT, Google OAuth
- **Source Code:** [BrainFood](https://github.com/TheVivekRajput002/FoodReel) | **Live:** [foody-reel.vercel.app](https://foody-reel.vercel.app/)
